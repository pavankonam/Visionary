JEWELRY CATEGORY IMAGES
=======================

Place your jewelry images in this folder with these exact names:

1. earrings.jpg   - Image for Earrings category
2. rings.jpg      - Image for Rings category
3. bracelet.jpg   - Image for Bracelet category
4. necklace.jpg   - Image for Necklace category

Requirements:
- Format: JPG or PNG
- Recommended size: 600x600px or larger
- Aspect ratio: Square (1:1) works best
- Style: High-quality jewelry photography on white/neutral background

The images will be displayed at 300px height with automatic width scaling.
They will have a subtle zoom effect on hover.
